# Как передать программу другому человеку

## Правильный способ

Передавай не один `exe`, а всю папку рядом с ним.

Минимально:

```text
WebExeStarter\
  WebExeStarter.exe
```

После первого запуска рядом автоматически появятся:

```text
WebExeStarter\
  WebExeStarter.exe
  db\
  logs\
```

## Если нужно передать уже настроенную программу

Передавай всю рабочую папку целиком:

```text
WebExeStarter\
  WebExeStarter.exe
  db\
    app.sqlite3
    templates\
  logs\
```

Тогда на другом компьютере сохранятся:

- база мероприятий
- схема зала
- шаблоны билетов
- настройки сводки

## Что нельзя делать

Не клади программу в:

- `C:\Program Files\`
- другие системные папки без прав записи

Лучше использовать:

- рабочий стол
- `D:\WebExeStarter\`
- любую обычную папку пользователя

## Если нужно обновить программу

Есть два варианта:

1. заменить только `WebExeStarter.exe`, оставив папки `db` и `logs`
2. заменить всю папку, если нужно перенести всё целиком

Если база уже рабочая, безопаснее менять только `exe`.

## Если на другом компьютере не запускается

Проверь лог:

```text
logs\launcher.log
```

или fallback:

```text
%LOCALAPPDATA%\WebExeStarter\logs\launcher.log
```

И уже по нему смотреть причину.
