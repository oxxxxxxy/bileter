# Как передать программу другому человеку

## Правильный способ

Передавай не один `exe`, а всю папку рядом с ним.

Минимально:

```text
WebExeStarter\
  WebExeStarter.exe
```

После первого запуска рядом автоматически появятся:

```text
WebExeStarter\
  WebExeStarter.exe
  db\
  logs\
```

## Если нужно передать уже настроенную программу

Передавай всю рабочую папку целиком:

```text
WebExeStarter\
  WebExeStarter.exe
  db\
    app.sqlite3
    templates\
  logs\
```

Тогда на другом компьютере сохранятся:

- база мероприятий
- схема зала
- шаблоны билетов
- настройки сводки

## Что нельзя делать

Не клади программу в:

- `C:\Program Files\`
- другие системные папки без прав записи

Лучше использовать:

- рабочий стол
- `D:\WebExeStarter\`
- любую обычную папку пользователя

## Если нужно обновить программу

Есть два варианта:

1. заменить только `WebExeStarter.exe`, оставив папки `db` и `logs`
2. заменить всю папку, если нужно перенести всё целиком

Если база уже рабочая, безопаснее менять только `exe`.

## Разрядность системы (32-бит vs 64-бит)

Из релизов собираются две версии:
- `WebExeStarter-x86.exe` (или переименованный в `Билеты.exe`) — **32-битная версия**. Работает **везде**: как на 32-битной Windows (старые компьютеры/кассы), так и на 64-битной Windows.
- `WebExeStarter-x64.exe` — **64-битная версия**. Работает только на 64-битной Windows.

> **Если на компьютере ошибка:**
> *«Эта версия не совместима с версией Windows, работающей на этом компьютере»*
> Это значит, что на 32-битной Windows попытались запустить 64-битную сборку. Используй версию **x86**.

## Что должно быть на компьютере пользователя

1. **Microsoft Visual C++ Redistributable 2015–2022 (x86)**:
   - Если программа не открывается или ругается на `vcruntime140.dll`, установите [vc_redist.x86.exe](https://aka.ms/vs/17/release/vc_redist.x86.exe).
2. **Драйвер принтера**:
   - Принтер билетов (например, `AIYIN_IP802BT`) должен быть подключен и установлен в Windows.

## Если на другом компьютере не запускается

Проверь лог:

```text
logs\launcher.log
```

или fallback:

```text
%LOCALAPPDATA%\WebExeStarter\logs\launcher.log
```

И уже по нему смотреть причину.
